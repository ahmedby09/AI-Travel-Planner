AI Travel Planner

A Java desktop application that uses AI to generate personalized travel plans based on a user's destination, trip duration, budget, and interests.

The project combines Java object-oriented programming, Java Swing and graphical user interface, HTTP API communication, and AI-generated travel recommendations.

Features

- Enter a travel destination
- Set the number of travel days
- Set a trip budget
- Select interests such as:
  - Food
  - Sightseeing
  - Outdoors
  - Shopping
  - Road trips
- Generate a personalized AI Plan
- Manage activities and restaurants
- Calculate total trip cost
- Calculate remaining budget
- Validate user input
- Handle API and network errors

Technologies Used

- Java
- Java Swing
- Object-Oriented Programming
- Java HttpClient
- Groq API
- JSON
- AI language models

Functionality

The user enters trip information through the Java Swing interface, including:

Destination
Number of days
Budget
Interests
